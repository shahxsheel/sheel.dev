About

Sheel Shah

CS at UC San Diego. I build things end to end, then keep showing up for them.

Most of what I've built starts as something that doesn't work yet: a robotic arm whose SDK refuses to run on my laptop, an inference pipeline too slow for the hardware it has to live on, a UI that has to stay honest under real-time load. I like the part where the problem stops being abstract.

I don't specialize in one layer. I've written firmware-adjacent CAN bus code, real-time computer vision on Raspberry Pi, React dashboards, and open-source tooling for AI agents. The through line is finishing: shipping the thing, then fixing what broke after.

This site is the short version. The code, the commits, and the messy middle live on GitHub.
